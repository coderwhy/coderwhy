## About Me

我喜欢把复杂的技术拆成可以运行、可以学习、可以复用的项目。这里主要沉淀前端学习路径、实战案例、跨端应用和工程化工具，希望每个仓库都能帮你少走一点弯路。

- Web engineering: JavaScript, TypeScript, Vue, React, Node.js
- Cross-platform practice: Mini Program, Swift, Flutter
- Developer experience: CLI tools, templates, state management, learning examples
- Content style: from fundamentals to practical projects
